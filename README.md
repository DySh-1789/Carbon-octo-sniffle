# Carbon-octo-sniffle

Воксельная 3D-танковая игра на Rust (`Bevy 0.20` + собственный воксельный и баллистический движок) в духе War Thunder и World of Tanks.

## Текущий прогресс

- [x] **Этап 1:** Базовая платформа, плоский воксельный мир (`0.5 м`), базовый воксельный танк (`0.2 м`), езда, башня, прицел и баллистическая стрельба
- [ ] **Этап 2:** Полноценная карта с рельефом, домами, позициями и подвеской по склонам
- [ ] **Этап 3:** Противники (командный бой с ботами и захватом точек)
- [ ] **Этап 4:** Система повреждений War Thunder (без HP) и обычный снаряд (`AP`)
- [ ] **Этап 5:** Разделение техники по нациям (США, Германия, СССР) и 8 уровням *(после утверждения списка)*
- [ ] **Этап 6:** Расширение каталога карт до 5
- [ ] **Этап 7:** Разрушаемость (дома, рельеф) и фугасные снаряды (`HE`)
- [ ] **Этап 8:** Каморные снаряды (`APHE`, `APHEBC`, `APCBC`)

## Запуск и тесты

```bash
# Запуск игры (рекомендуется --release или dev-профиль с оптимизацией зависимостей)
cargo run -p game

# Прогон всех автоматических тестов (voxel, sim, headless Bevy ECS)
cargo test --workspace

# Проверка линтером
cargo clippy --workspace --all-targets --no-deps -- -D warnings
```

## Управление (Этап 1)

| Клавиша | Действие |
|---|---|
| `W` / `S` | Газ вперёд / задний ход и торможение |
| `A` / `D` | Разворот корпуса влево / вправо |
| `Мышь` | Наведение камеры и башни (клик по окну фиксирует курсор) |
| `ЛКМ` / `Space` | Выстрел основным орудием |
| `Shift` | Переключение «3-е лицо ↔ Снайперский прицел наводчика» |
| `C` (удерживать) | Свободный обзор без поворота башни |
| `Колёсико мыши` | Приближение / отдаление камеры или кратность прицела |
| `Esc` | Освободить курсор мыши |
