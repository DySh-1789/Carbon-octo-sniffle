# Carbon Armor (`carbon-armor` v0.1)

Воксельная 3D-танковая игра на Rust (`Bevy 0.20` + собственный воксельный и баллистический движок) в духе War Thunder и World of Tanks.

🎮 **Играть в браузере (GitHub Pages / WebAssembly + WebGL2):**  
https://dysh-1789.github.io/carbon-armor/

## Базовый план разработки (8 этапов — завершено!)

- [x] **Этап 1:** Базовая платформа, плоский воксельный мир (`0.5 м`), базовый воксельный танк, езда, башня, прицел и баллистическая стрельба
- [x] **Этап 2:** Полноценная карта **«Европейская долина»** (`384 × 384 м`) с рельефом, деревней, церковью, каменным мостом, тактическими позициями `A/B/C`, 6-точечной подвеской по склонам, коллизиями со зданиями, атмосферным туманом и тактической миникартой
- [x] **Этап 3:** Противники — командный бой `6v6` с AI-ботами (`NavGrid` + A*), захватом точек `A/B/C`, тикетами, системой засвета (LOS), физикой столкновений и поражением танков
- [x] **Этап 4:** Система повреждений War Thunder (без HP — приведённая броня `RHA/CHA`, оверматч, рикошеты, конус осколков `AP`, 9 типов модулей, экипаж с 6-сек пересадкой, пожары, подрыв БК с отрывом башни, схема модулей и Hit-Cam) и бронебойный снаряд (`AP`)
- [x] **Этап 5:** Разделение техники по 3 нациям (**США**, **Германия**, **СССР**) × 8 уровней (`24` исторические машины, вкл. **M4A3E2 (76) W** и **T-44-100**), сверхдетализированные воксельные модели (`0.05 м` с фасками наклонной брони, протектором траков, 3-цветным немецким камуфляжем, объёмными дульными тормозами, шанцевым инструментом, тросами, дымовыми гранатомётами и поручнями десанта), аутентичные процедурные флаги, индустриальный 3D-Ангар, интерактивное Дерево развития (drag & click), уровневый матчмейкинг `6v6` и боевой HUD в стиле War Thunder
- [x] **Этап 6:** Расширение каталога карт до **5 тактических локаций** (`384 × 384 м`) с индивидуальной атмосферой и выбором карты в Ангаре:
  1. **European Valley** — европейская долина с деревней и каменным мостом
  2. **El Alamein** — пустыня Северной Африки с песчаными дюнами, руинами и каньоном
  3. **Stalingrad Winter** — зимний Сталинград со снежным заводским комплексом и замерзшей рекой
  4. **Karelia Ridge** — карельский сосновый хребет с гранитными утёсами и дотами
  5. **Normandy Bocage** — Нормандия с бокажем, деревней и бункерами
- [x] **Этап 7:** Разрушаемость воксельного мира в реальном времени (разрушение кирпичных/деревянных домов, стен и воронок в рельефе с разлётом обломков и перестроением чанков) и фугасные снаряды (`HE`) с ударной волной по внешним модулям и механикой избыточного давления (**Overpressure**)
- [x] **Этап 8:** Каморные снаряды (**`APHE`**, **`APHEBC`**, **`APCBC`**) с чувствительностью и задержкой взрывателя, сферическим внутренним взрывом `360°` после пробития, перепробитием тонкой брони без взведения и переключением типов боеприпасов `[1] / [2] / [3]`

## Обновление 0.1 — Экономика и прогрессия

После завершения всех 8 базовых этапов добавлена полноценная система экономики и развития техники:

- **Две валюты:**
  - **Серебряные кредиты (`CR`)** — общая валюта для покупки исследованных машин и оплаты послебоевого ремонта. Стартовый баланс: `2 500 CR`.
  - **Очки исследования (`RP`)** — начисляются раздельно по нациям (`USA RP`, `GERMANY RP`, `USSR RP`) для исследования следующего уровня в ветке.
- **Бесплатные резервы I уровня (защита от софт-лока):**
  - Стартовые танки **M2A4** (США), **Pz.II C** (Германия) и **БТ-5** (СССР) доступны бесплатно сразу в Ангаре и имеют ремонт `0 CR`.
- **Последовательное Дерево развития (I → VIII уровни):**
  - Для исследования танка уровня `N` требуется владеть машиной уровня `N-1` этой нации.
  - После исследования за `RP` машина покупается за `CR` и становится доступна для выхода в бой прямо из Ангара или Дерева развития.
- **Послебоевой расчёт и ремонт:**
  - Награды за бой (`CR` и `RP`) зависят от уровня техники, победы (`×1.5`), числа фрагов, пробитий и удержанных точек `A/B/C`.
  - Если машина уничтожена (кроме бесплатных резервов I уровня), вычитается стоимость ремонта (баланс никогда не уходит в минус).
  - Детализированная квитанция отображается на экране итогов боя и в ленте Ангара.
- **Сохранение прогресса:**
  - В нативной версии профиль автоматически сохраняется в `~/.carbon_armor_profile.txt`, а в браузерной WebAssembly-версии — в `localStorage` после каждого боя, исследования или покупки.

## Боевые механики и тактические улучшения

- **Полевой ремонт (`F`) и огнетушитель FPE (`6`):**
  - Каждая машина несёт `2` заряда огнетушителя (`[6]`) для мгновенного тушения пожара двигателя/баков.
  - Клавиша `[F]` (на месте) запускает полевой ремонт выбитых гусениц, ствола, казённика, двигателя или трансмиссии (можно отменить повторным нажатием `[F]`).
- **Живой индикатор пробития, дальномер и баллистическая поправка:**
  - При наведении на противника прицел в реальном времени рассчитывает падение бронепробития с дистанцией (De Marre) и приведённую броню плиты, подсвечивая маркер зелёным / жёлтым / красным и отображая дальность.
  - В снайперском прицеле отображается динамический баллистический маркер падения снаряда с учётом гравитации и аэродинамического сопротивления выбранного типа боеприпаса.
- **Обратная связь в бою и 3D-поле боя:**
  - Направленный индикатор попаданий, отдача камеры по калибру орудия, 3D-маяки границ точек `A/B/C`, полоса захвата точки, пыль из-под гусениц и брызги при форсировании рек, а также мгновенное восстановление разрушенных зданий при перезапуске боя.
- **Улучшенный AI ботов:**
  - Боты ромбуют корпус при перестрелке, выбирают `HE` против открытых целей, тушат пожары, чинят выбитые модули и распределяются по точкам `A/B/C`.

## Запуск и тесты

```bash
# Запуск нативной версии
cargo run -p game

# Прогон всех автоматических тестов (voxel, sim, economy, 5 карт, headless Bevy ECS)
cargo test --workspace

# Проверка линтером
cargo clippy --workspace --all-targets --no-deps -- -D warnings
```

## Управление

| Клавиша | Действие |
|---|---|
| `Мышь (в Ангаре)` | Вращение камеры вокруг 3D-танка на подиуме (`R` — вернуть авто-обзор), колёсико — зум |
| `1`–`8` / `Q` / `E` (в Ангаре) | Выбор уровня `I–VIII` / переключение нации |
| `←` / `→` или `< / >` (в Ангаре) | Выбор одной из 5 карт |
| `Tab` (в Ангаре) | Переключение **Ангар ↔ Дерево развития** |
| `Перетаскивание / колёсико / клик (Дерево)` | Панорамирование дерева исследований I–VIII, клик — выбор машины, повторный клик — исследование/покупка (`CENTER` — центрировать) |
| `Enter` / кнопка действия | Выход в бой (`BATTLE!`), исследование (`RESEARCH`) или покупка (`BUY`) выбранного танка |
| `W` / `S` | Газ вперёд / задний ход и торможение |
| `Q` / `E` | Круиз-контроль (`CR / N / CC1 / CC2`); после уничтожения — переключение камеры наблюдения по союзникам |
| `A` / `D` | Разворот корпуса влево / вправо |
| `Мышь (в бою)` | Наведение камеры и башни (клик по окну фиксирует курсор) |
| `ЛКМ` / `Space` | Выстрел основным орудием |
| `1` / `2` / `3` | Переключение типа снаряда (`APCBC` / `APHEBC` / `APHE` / `AP` / `HE`) |
| `6` | Огнетушитель (`FPE`, 2 заряда на бой) |
| `F` | Полевой ремонт повреждённых/выбитых модулей (повторное нажатие — отмена) |
| `Shift` | Переключение «3-е лицо ↔ Снайперский прицел наводчика» |
| `C` (удерживать) | Свободный обзор без поворота башни |
| `Tab` (удерживать в бою) | Таблица состава команд `6v6` (фраги, пробития, статус) |
| `Колёсико мыши` | Приближение / отдаление камеры или кратность прицела |
| `Esc` | Освободить курсор мыши (позволяет нажать `< HANGAR` или кликнуть по слотам HUD) |
| `H` / `TO HANGAR` | Вернуться в Ангар (после уничтожения или окончания боя) |
| `Enter` / `PLAY AGAIN` | Перезапустить бой после уничтожения или окончания матча |
